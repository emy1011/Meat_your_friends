# Meat\_your\_friends



bienvenue dans notre jeu



Nombre de joueur : Jeu en 2 vs 2 vs ... 

But du jeu : L'objectif est d'obtenir un maximum de point par rapport aux autres équipes en un temps limité (5/10 min)

Comment obtenir des Points : - Faire des plats avec les différents ingrédients qui auront été chassé/cultivé/trouvé sur la carte.

&#x09;	             - Les recettes sont prédéfinies et la difficulté à obtenir les ingrédients détermine le nombre de points.

&#x09;		     - On peu frapper les animaux pour obtenir de la viande, frapper les joueur pour les étoudir/ faire tomber leurs ingrédients, faire une action de culture pour obtenir des légumes.

La carte : Carte définie avec différents environnements dans un style un peu rétro/pixel.
